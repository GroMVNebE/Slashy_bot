# Дискорд-бот Slashy 👾
Многофункциональный дискорд-бот, работающий на `discord-py`, `python-3.11.9`, `PostgreSQL`

## Установка 🛠️
1. Склонируйте репозиторий
```
git clone https://github.com/GroMVNebE/Slashy_bot.git
```
2. Создайте и запустите виртуальное окружение (`venv`)
```
python3 -m venv venv
```
Запуск через `CMD` на `Windows`
```
venv\Scripts\activate.bat
```
Запуск через терминал `Linux`
```
source venv/bin/activate
```
3. Установите зависимости
```
pip install -r requirements.txt
```
4. Создайте базу данных на PostgreSQL, используя любой удобный способ, пр. [pgAdmin](https://www.pgadmin.org/)
5. Создайте файл конфигурации `.env`
```
DISCORD_TOKEN=ТОКЕН_ДИСКОРД_БОТА
DATABASE_URL=postgresql://ИМЯ_ПОЛЬЗОВАТЕЛЯ_БД:ПАРОЛЬ@АДРЕС_БД:ПОРТ_БД/ИМЯ_БД
CREATOR_ID=ВАШ_DISCORD_ID
BOT_ID=DISCORD_ID_БОТА
LOGGER_LEVEL=ЛЮБОЙ_УДОБНЫЙ_ИЗ_СПИСКА[ERROR | WARNING | INFO | DEBUG]
```
6. Запустите бота
```
python launch.py
```
## Текущий функционал ⚙️
### Для пользователей 👤
- **Система уровней** за активность на сервере: начисление опыта за **отправку сообщений**, **угадывание числа в `guess`**
- **Карточка пользователя**, отображающая текущий уровень с прогресс-баром (`/lvl`)
- Игра **Угадай число от 1 до 1000**, один из видов интересной активности (`/guess`)
- **Генератор случайных чисел**, использующий переданный пользователем диапазон. Полезно при решении споров или когда трудно выбрать что-то одно (`/rand`)
- **Трекинг времени "общения"**, позволяющий посмотреть время "общения" в голосовых каналах за выбранную *неделю*/*месяц*/*год* (`/voice`). Для сбора данной информации владелец сервера должен разрешить это в параметрах бота, используя `/setup`. Пользователь может в любой момент запретить сбор данных, используя `/setup`
- **Детальный трекинг сессий "общения"**, сохраняющий временные интервалы "общения" (`/sessions`). Сбор детальных сессий изначально отключен, но может быть разрешён в настройках `/setup`. В отличие от общей статистики времени "общения" (`/voice`), детальную статистику может просматривать **только** её **владелец**
### Для владельца/разработчика 🕵🏻
- Управления ботом прямо из Discord (`/manage`):  
`- возможность перезапустить модуль для обновления без остановки бота`  
`- возможность выключить бота`

## Особенности 🔧
- Поддержка `слеш-команд` Discord
- Ограничение частоты использования команд *(пр. `/lvl` можно использовать 1 раз в 5 секунд)*
- Обработка ошибок при использовании команд с подробным логгированием
- Использование UI-элементов из Discord API - *Embed, View, Modal, Button, Select*
