# Дискорд-бот Slashy 👾
Многофункциональный дискорд-бот, работающий на `discord-py`, `python-3.11.9`, `PostgreSQL`

## Установка 🛠️
1. Склонируйте репозиторий
```
git clone https://github.com/GroMVNebE/Slashy_bot.git
```
2. Установите зависимости
```
pip install -r requirements.txt
```
3. Создайте файл конфигурации `.env`
```
DISCORD_TOKEN=Токен_Вашего_бота
DATABASE_URL=URL_для_подключения_базы_данных_PostgreSQL
CREATOR_ID=Ваш_Discord_ID
BOT_ID=Discord_ID_бота
```
4. Запустите бота
```
python launch.py
```
## Текущий функционал ⚙️
- Начисление опыта пользователям за проявление активности (отправку сообщений, участие в мини-игре)
- Возможность посмотреть текущий уровень с помощью команды `/lvl` в виде карточки с прогресс-баром
- Мини-игра на угадывание числа от `1` до `1000` с помощью команды `/guess`
- Возможность генерации случайного числа в заданном пользователем диапазоне с помощью команды `/rand`
- Управления ботом прямо из Discord:  
`- возможность перезапустить модуль для обновления без остановки бота;`  
`- возможность выключить бота`
- Возможность настроить бота на каждом отдельном сервере:  
`- управление функцией отслеживания времени "общения" пользователей`
- Отслеживание времени общения пользователей в голосовом канале *(собирает для каждого пользователя статистику о проведённом в голосовом канале времени, если в канале находится хотя бы 2 пользователя)*

## Особенности 🔧
- Поддержка слеш-команд Discord
- Ограничение частоты использования команд *(пр. команду `lvl` можно использовать 1 раз в 5 секунд)*
- Обработка ошибок при использовании команд с подробным логгированием
- Использование UI-элементов, предлагаемых Discord API - *Embed, View, Modal, Button, Select*
